# Datasets

This directory contains documentation related to the datasets used in the **KNN Research Study**.

The datasets are identified from the research papers analyzed in this study and are obtained from publicly available sources, such as Kaggle.

## Dataset Sources

The actual datasets are **not stored in this repository** to avoid unnecessarily increasing repository size and to respect the terms and licensing of the original dataset sources.

Dataset information and source links are maintained in:

```text
../papers/paper_metadata.csv
```

## Dataset Selection

For each research paper, the following information is recorded where available:

* Dataset name
* Original research paper
* Dataset source
* Kaggle link
* Number of samples
* Number of features
* Target variable
* Classification task
* Relevant dataset characteristics

## Reproducibility

Before running an experiment, the required dataset should be obtained from its documented source and placed or loaded into the appropriate notebook/environment.

Dataset-specific preprocessing and preparation steps are documented within the corresponding experiment notebooks.
